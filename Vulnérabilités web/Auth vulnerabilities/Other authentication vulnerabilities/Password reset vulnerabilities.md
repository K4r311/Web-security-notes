Plusieurs applications web on une fonctionnalité pour reset les mots de passe des utilisateurs qui les ont oublié.

Cependant, cette fonctionnalité peut être utilisée par un attaquant pour réinitialiser le mot de passe de la victime a sa place. Celui-ci peut voler son token pour y parvenir. 

L'attaquant peut également exploiter la différence entre les réponses pour procéder a une énumération et enfin tomber sur le mot de passe valide, sur la page de modification de mots de passe.

Le formulaire de réinitialisation de mots de passe peut aussi être utilisé pour `énumérer` les utilisateurs sur une application web.
